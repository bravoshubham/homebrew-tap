## RigWatch

Mission control for a developer's Mac: coding agents, emulators, builds and caches, at a glance.
Source and screenshots: [bravoshubham/rigwatch](https://github.com/bravoshubham/rigwatch).

```bash
brew install bravoshubham/tap/rigwatch
```

RigWatch is built on your Mac from source (about a minute; needs macOS 14 or later and the
Xcode Command Line Tools, which Homebrew already installs). Because it is built locally, macOS
opens it without a Gatekeeper warning. Start it with `rigwatch`. Update with `brew upgrade`.
